# كود موبايل – Smart Mobile Codes (بداية المشروع)

هذا أرشيف مصدر أولي قابل للتطوير، وليس APK جاهزاً أو إصداراً مختبراً للنشر.

## الموجود في هذه النسخة
- واجهة Flutter عربية حديثة.
- بطاقات أكواد مع بحث وتصنيف حسب الشركة.
- مفضلة محفوظة محلياً.
- نسخ الكود وفتح تطبيق الاتصال عبر `tel:`.
- إعدادات الوضع الفاتح/الداكن حسب النظام.
- اعتماد مبدئي على `home_widget` تمهيداً للويدجت.

## تنبيه مهم حول الأكواد
الأكواد الموجودة في `lib/data/seed_codes.dart` بيانات تجريبية فقط، وعليها علامة «لم يتم التحقق منه رسمياً». يجب التحقق من كل كود وشروطه من الموقع الرسمي للشركة قبل إزالة العلامة أو نشر التطبيق. لا تضمن واجهة `tel:` تشغيل USSD تلقائياً؛ غالباً تفتح شاشة الاتصال ويؤكد المستخدم التنفيذ، وقد يختلف سلوك اختيار الشريحة حسب الجهاز.

## إنشاء مشروع Android كامل
1. ثبّت Flutter SDK وAndroid SDK على الكمبيوتر أو بيئة تطوير مناسبة.
2. نفّذ: `flutter create --org com.example smart_mobile_codes`
3. استبدل `pubspec.yaml` ومجلد `lib` بالملفات الموجودة في هذا الأرشيف.
4. نفّذ: `flutter pub get`
5. نفّذ: `flutter analyze`
6. نفّذ: `flutter run` على هاتف Android حقيقي.

## بناء APK تجريبي
`flutter build apk --debug`

وللإصدار النهائي نحتاج إعداد مفتاح توقيع release، واختبارات على أجهزة فعلية، ومراجعة سياسات Google Play والخصوصية.

## ملفات Android الإضافية
المجلد `android_overlay` مخصص لإضافة مستقبلية لويدجت Android أصلية. لم يتم دمجه تلقائياً في مشروع مولّد بعد، ولم تُختبر الويدجت في هذه النسخة.
